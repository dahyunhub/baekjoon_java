# Algorithm Solutions

백준과 SWEA 알고리즘 문제 풀이를 정리한 저장소입니다. 대부분 Java로 풀이했으며, 문제별 폴더에는 풀이 소스와 문제 README, 필요 시 로컬 테스트용 `input.txt`/`output.txt`가 함께 들어 있습니다.

## 프로젝트 구조

```text
.
├── 백준
│   ├── Bronze
│   │   └── {문제번호}. {문제명}
│   ├── Silver
│   │   └── {문제번호}. {문제명}
│   └── Gold
│       └── {문제번호}. {문제명}
├── SWEA
│   ├── D2
│   │   └── {문제번호}. {문제명}
│   └── D3
│       └── {문제번호}. {문제명}
├── LICENSE
└── README.md
```

각 문제 폴더는 보통 아래 형태로 구성됩니다.

```text
{문제번호}. {문제명}/
├── README.md
├── {문제명}.java
├── input.txt
└── output.txt
```
