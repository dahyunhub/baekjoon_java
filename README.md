# Algorithm Solutions

백준과 SWEA 알고리즘 문제 풀이를 정리한 저장소입니다. 문제별 폴더에는 풀이 코드와 문제 설명 README, 필요하면 로컬 테스트용 입력/출력 파일을 함께 보관합니다.

## 프로젝트 구조

```text
.
├── 백준
│   ├── Bronze
│   ├── Silver
│   └── Gold
├── SWEA
│   ├── D2
│   └── D3
├── LICENSE
└── README.md
```

## 풀이 현황

중복 저장된 같은 문제 번호는 하나의 풀이로 집계했습니다.

| 플랫폼 | 난이도 | 풀이 수 |
| --- | --- | ---: |
| 백준 | Bronze | 85 |
| 백준 | Silver | 34 |
| 백준 | Gold | 6 |
| SWEA | D2 | 2 |

| **합계** |  | **129** |

## 메모

- 풀이 코드는 각 문제 폴더 안에서 관리합니다.
